# AT-21 — Product Detail Page

## Goal
Create a dedicated product detail page that shows full information about a single product when a user clicks on a product card.

## Requirements

### Page
- Route: `/products/:productId`
- Title: Product name (dynamic)
- Fetch product by ID: `getProductById(productId)`
- Show full product details:
  - Large product image
  - Product name
  - Price with currency
  - Description (full text)
  - Unit
  - Store name (linked to store products page)
  - Stock availability indicator
- Add to cart functionality with quantity selector
- Loading state while fetching
- Error state with retry button
- "Back to products" navigation link

### Navigation
- Product cards on home page, products page, and store products page should link to the product detail page
- Update `ProductCard` component to wrap in a link

### URL Structure
- `/products/:productId` - Individual product page
