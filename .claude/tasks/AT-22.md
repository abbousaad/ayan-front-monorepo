# AT-22 — All-Products Page Redesign: White Background + Store Filter Bar

## Goal
Redesign the `/products` page with a clean white background, remove the static editorial header copy ("Curated essentials / Thoughtfully stocked pantry favorites."), and add a horizontal row of store avatar circles that dynamically filter products by store when clicked. Selected store is highlighted; others appear grayed out.

## Requirements

### Background
- Change `<main>` background from `bg-[#f7f2ea]` to `bg-white`
- Change header `<section>` background from `bg-[#fbf7f1]` to `bg-white`

### Header Copy
- Remove the amber eyebrow `<p>Curated essentials</p>`
- Remove the `<h1>Thoughtfully stocked pantry favorites.</h1>`
- Remove the long description `<p>Browse the latest products…</p>`
- Replace with a simple `<h1>All Products</h1>` heading

### Store Filter Bar
- Fetch all stores on mount (parallel with product fetch) using `getStores()`
- Render a horizontal scrollable row of store circles above the product grid
- First item: an "All" circle button (icon or text), selected when no store filter is active
- Each store circle: 64×64px `rounded-full` image via `createImageUrl(store.imageUrl)`, store name below in truncated small text
- **Selected state**: colored ring (`ring-2 ring-offset-2 ring-amber-600`), full-color image
- **Unselected state**: `grayscale opacity-50`, no ring
- Show 4 gray placeholder circles while stores are loading

### Filtering Logic
- `selectedStoreId: string | null` — `null` means "All"
- Clicking a store circle: if already selected → deselect (fetch all products); otherwise fetch `getProducts({ storeId: store.id })`
- Clicking "All": deselect any store, fetch all products
- Re-use the existing `loadProducts` / subscription pattern; just pass `storeId` to `getProducts()`

### Product Count Tile
- "Available now" count reflects the currently displayed (filtered) products — already correct since it reads `products.length`

### StoreFilterBar (inline component)
```tsx
const StoreFilterBar = ({ stores, isLoading, selectedStoreId, onSelect }) => (
  <div className="flex gap-4 overflow-x-auto pb-2">
    {/* All button */}
    <button onClick={() => onSelect(null)} className="flex flex-col items-center gap-1">
      <div className={`w-16 h-16 rounded-full flex items-center justify-center bg-amber-50
        ${selectedStoreId === null ? 'ring-2 ring-offset-2 ring-amber-600' : 'grayscale opacity-50'}`}>
        All
      </div>
      <span className="text-xs text-stone-600">All</span>
    </button>
    {/* Store circles */}
    {isLoading
      ? Array.from({ length: 4 }).map((_, i) => (
          <div key={i} className="w-16 h-16 rounded-full bg-stone-100 animate-pulse" />
        ))
      : stores.map((store) => (
          <button key={store.id} onClick={() => onSelect(store.id)}
            className="flex flex-col items-center gap-1 min-w-[72px]">
            <img
              src={createImageUrl(store.imageUrl)}
              alt={store.name}
              className={`w-16 h-16 rounded-full object-cover
                ${selectedStoreId === store.id
                  ? 'ring-2 ring-offset-2 ring-amber-600'
                  : 'grayscale opacity-50'}`}
            />
            <span className="text-xs text-stone-600 truncate max-w-[72px] text-center">{store.name}</span>
          </button>
        ))
    }
  </div>
);
```
