# MT-10 — Mobile RTL via I18nManager

## Goal
Support Arabic RTL on mobile.

## Requirements
- On `setLocale`, compute `dir` from `@acme/shared` `getDirection`.
- Apply `I18nManager.allowRTL(true)` + `I18nManager.forceRTL(dir === 'rtl')`.
- Because RN needs a reload for full mirroring, prompt the user and call
  `Updates.reloadAsync()` (expo-updates) when the direction actually changes;
  document this constraint in the task/PR notes.
- Audit main screens for hardcoded `flexDirection: 'row'` / left-right padding that
  won't auto-mirror; drive from `dir` where needed.

## Done when
- [ ] Selecting Arabic mirrors the UI after reload; switching back restores LTR
- [ ] `pnpm lint` passes
