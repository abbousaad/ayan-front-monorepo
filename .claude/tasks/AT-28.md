# AT-28 — Admin translations editor page

## Goal
Let an admin edit translations, the default locale, and active locales — persisted
via `updateTranslationSetting`.

## Requirements
- `apps/web/src/routes/admin/admin-translations-page.tsx` — model on
  `admin-theme-page.tsx` / `admin-currency-page.tsx` (react-hook-form + `useAdminAuth`):
  - Load via `getTranslationSetting()`.
  - Controls: default-locale selector, active-locale toggles, and an editable
    key × locale grid (rows = `enBaseline` keys, columns = active locales; English
    baseline shown as read-only reference per row).
  - Save via `updateTranslationSetting(input, token)`; success/error messaging like
    the currency page.
- `apps/web/src/router.tsx` — add `{ path: 'translations', element: <AdminTranslationsPage /> }`
  under the admin layout.
- `apps/web/src/admin/admin-layout.tsx` — add `{ label: 'Translations', to: '/admin/translations' }`.

## Done when
- [ ] Editing + saving a string round-trips against the API (or fails gracefully offline)
- [ ] Route + nav link present
- [ ] `pnpm lint` passes
