# AT-12 — Admin dashboard with stat tiles

## Goal

Build an admin dashboard landing page that displays high-level statistics (stat tiles) at a glance. This serves as the entry point when admins log in to the admin panel (`/admin`).

## Key files to create/modify

- `apps/web/src/routes/admin/admin-dashboard-page.tsx` — the main dashboard component
- `apps/web/src/components/admin/shared/stat-tile.tsx` — reusable stat tile component (optional: create if multiple tiles needed)
- `apps/web/src/router.tsx` — add route mapping if not already present

## Constraints

- Use existing Tailwind v4 and React 19 patterns from other admin pages
- Keep styling consistent with the admin UI (existing color scheme, spacing)
- Stat data can be mocked initially; endpoint integration is not required for this task
- Dashboard should be responsive

## Done when

- [ ] Admin dashboard page renders at `/admin` with at least 3 stat tiles (e.g., total orders, total revenue, active coupons)
- [ ] Each tile displays a metric label, value, and optional trend/icon
- [ ] Dashboard styling is consistent with the admin panel design
- [ ] `pnpm --filter web lint` passes
- [ ] Task marked `[x]` in `.claude/tasks/active.md`
