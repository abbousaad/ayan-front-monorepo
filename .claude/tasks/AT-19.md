# AT-19 — Admin API client for currency settings

## Goal
Add admin API client functions and types for currency settings.

## Requirements

### Endpoints
- `getCurrencySetting(token: string): Promise<CurrencySetting>`
  - `GET /settings/currency` (authenticated)
- `updateCurrencySetting(input: CurrencySettingInput, token: string): Promise<CurrencySetting>`
  - `PATCH /settings/currency` (superadmin only)

### Types
- `CurrencySetting`: `{ currencyCode: string }`
- `CurrencySettingInput`: `{ currencyCode: string }`

### Validation
- Add a parser/validator that ensures `currencyCode` is a string.
- Throw `ApiClientError` if the response does not match expected shape.

### Exports
- Export functions and types from `packages/api-client/src/admin/index.ts`.
