# B-6 — Simplify guest checkout to name and phone only

## Goal

Reduce the mobile guest checkout form to only the fields needed for the current release and force all deliveries to `instant`.

## Files to modify
- `apps/mobile/src/checkout-screen.tsx`

## Fixes

### Remove from UI
- Delivery address
- Email
- Delivery mode chooser
- Scheduled date/time

### Keep in UI
- Full name
- Phone number

### Submission behavior
- Always submit `deliveryMode: 'instant'`.
- Remove scheduled delivery logic from validation and submit flow.
- Keep backend compatibility in mind for the guest address field if the API still expects a string in responses.

## Done when
- [ ] Only full name and phone number are shown
- [ ] Validation only applies to those fields
- [ ] Orders always submit with `deliveryMode: 'instant'`
- [ ] `pnpm --filter mobile lint` passes
- [ ] Task marked done in `.claude/tasks/activemobile.md`
