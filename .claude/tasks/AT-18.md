# AT-18 — Cart + checkout UI pricing display

## Goal
Fetch pricing config once and display delivery fee, discount, and total in cart sidebar and checkout summary.

## Requirements

### Pricing config hook
- Create `usePricingConfig()` hook that fetches via `getPublicPricingConfig()`.
- Return `{ pricingConfig, isLoading, error }` with fallback `{ deliveryFee: 0, discountRate: 0 }` on failure.
- Do not block checkout submission if pricing config fails.

### Cart sidebar
- Show line items: Subtotal, Discount, Delivery Fee, Total.
- Use shared pricing helpers from `@acme/cart` for calculations.
- Discount applies to subtotal + delivery fee.
- Format currency consistently with existing UI.

### Checkout summary
- Show the same line items and total.
- Ensure values update when cart contents change.
