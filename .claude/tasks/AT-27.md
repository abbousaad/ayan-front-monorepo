# AT-27 — Web RTL pass

## Goal
Make the web store UI mirror correctly under `dir="rtl"` (Arabic).

## Requirements
- Provider already sets `<html dir>` (AT-25). Do a directional-utility pass:
  swap physical Tailwind utilities for logical ones — `ml-`→`ms-`, `mr-`→`me-`,
  `pl-`→`ps-`, `pr-`→`pe-`, `text-left`→`text-start`, `text-right`→`text-end`,
  `left-`/`right-` → `start-`/`end-` — and add `rtl:`/`ltr:` variants where a
  component must physically mirror (e.g. chevrons, slide-in cart sidebar).
- Focus files: `navbar.tsx`, `components/cart/cart-sidebar.tsx`, `product-card.tsx`,
  `components/checkout/*`. Tailwind v4 supports logical properties natively.

## Done when
- [ ] Arabic renders mirrored with no clipped/overlapping layout on key screens
- [ ] LTR (en/fr) visually unchanged
- [ ] `pnpm lint` passes
