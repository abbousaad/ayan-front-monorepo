# AT-14 — Add public-orders API client functions

## Goal
Add API client functions for all public-orders endpoints to the `@acme/api-client/admin` module.

## Requirements

### New functions in `packages/api-client/src/admin/public-orders.ts`
- `listPublicOrders(token: string, status?: PublicOrderStatus): Promise<unknown>` -- calls `GET /public-orders` with optional `?status=` query param
- `confirmPublicOrder(id: string, token: string): Promise<void>` -- calls `PATCH /public-orders/{id}/confirm`
- `acceptPublicOrderDelivery(id: string, token: string): Promise<void>` -- calls `PATCH /public-orders/{id}/accept-delivery`
- `markPublicOrderPaid(id: string, token: string): Promise<void>` -- calls `PATCH /public-orders/{id}/mark-paid`

### Types in `packages/api-client/src/admin/types.ts`
- Add `PublicOrderStatus` type: `'pending' | 'onpreparation' | 'ondelivery' | 'paid'`
- Add `PublicOrder` type with at minimum: `{ id: string; status: PublicOrderStatus; [key: string]: unknown }` -- keep it loose since the API response schema is not fully documented. The page will display whatever fields come back.

### Re-export from index
- Export all new functions from `packages/api-client/src/admin/index.ts`
- Export `PublicOrderStatus` and `PublicOrder` types from the same index
