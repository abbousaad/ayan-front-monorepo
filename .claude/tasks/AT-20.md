# AT-20 — Admin currency settings screen + route

## Goal
Create an admin screen to view/update the global currency code.

## Requirements

### Page
- Route: `/admin/currency`
- Title: “Currency Settings”
- Single text input for `currencyCode`
- Fetch on mount: `getCurrencySetting(token)`
- Save on submit: `updateCurrencySetting({ currencyCode }, token)`
- Show green success banner and red error banner
- Show loading state while fetching

### Navigation
- Add “Currency” link after “Pricing” in the admin sidebar

### Auth handling
- Use `useAdminAuth()`; on 401, call `handleUnauthorized()`
