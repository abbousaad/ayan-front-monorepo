# AT-17 — Public pricing config data access + pricing math

## Goal
Expose public pricing config (delivery fee + discount rate) and shared pricing math for cart/checkout totals.

## Requirements

### Pricing config API
- Add a public API client function `getPublicPricingConfig()` calling `GET /orders/pricing-config` (no token).
- Parse/validate response; if request fails or response missing fields, fallback to `{ deliveryFee: 0, discountRate: 0 }`.

### Types
- Add `PricingConfig` type for public usage with:
  - `deliveryFee: number`
  - `discountRate: number`
- Re-export from the orders module and top-level index.

### Pricing math
- Add pure helpers to compute:
  - `discountBase = subtotal + deliveryFee`
  - `discountAmount = discountBase * discountRate`
  - `total = subtotal + deliveryFee - discountAmount`
- Discount applies to **subtotal + delivery fee**.
- Helpers live in `packages/cart` (shared) to reuse in web UI.
