# AT-23 — Shared i18n core

## Goal
Provide the shared, cross-app i18n primitives: locale metadata, the English
baseline key set, and a pure `translate` + `Intl` formatting helpers. Single
source of truth for keys used by web and mobile.

## Files created
- `packages/shared/src/i18n/locales.ts` — `Locale`, `LOCALES` (en/fr/ar with `dir`),
  `DEFAULT_LOCALE`, `isLocale`, `getLocaleMeta`, `getDirection`.
- `packages/shared/src/i18n/baseline.ts` — `enBaseline` (namespaced strings) + `TranslationKey`.
- `packages/shared/src/i18n/translate.ts` — `translate(bundle, key, params?)` with
  `{param}` interpolation + baseline fallback; `formatCurrency`, `formatNumber`.
- `packages/shared/src/index.ts` — re-exports all of the above.
