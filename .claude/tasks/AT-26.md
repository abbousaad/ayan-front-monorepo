# AT-26 — Web string extraction pass

## Goal
Replace hardcoded user-facing text in the web store UI with `t('...')`, adding each
new string as a key in `packages/shared/src/i18n/baseline.ts`.

## Scope (store-facing only; admin covered by AT-28)
- `components/navbar.tsx`, `routes/home-page.tsx`, `components/product-card.tsx`,
  `routes/product-page.tsx`, `routes/products-page.tsx`, `routes/store-products-page.tsx`,
  `components/cart/*`, `components/checkout/*`, `routes/checkout-page.tsx`.

## Rules
- Every new string → new key in `enBaseline` (namespaced), then referenced via `t()`.
- Keep keys stable and descriptive; reuse `common.*` for shared words.
- No behavior/layout change beyond text sourcing.

## Done when
- [ ] No hardcoded display strings remain in the scoped files
- [ ] All referenced keys exist in `enBaseline` (tsc enforces `TranslationKey`)
- [ ] `pnpm lint` passes
