# AT-10 — Admin Orders Screen

## Goal

Build the `/admin/orders` page. No list-all-orders endpoint exists in the API, so this is a simple "confirm order by ID" tool.

## Requirements

### Page layout
- Title "Orders"
- Info banner: "No order listing endpoint is available yet. Use the form below to confirm pending orders by ID."
- A form with: Order ID text input + "Confirm Order" button
- Success message: "Order {id} confirmed — moved to 'onpreparation'"
- Error message on failure (e.g. invalid ID, order already confirmed)

### Data flow
1. Admin enters an order ID
2. Clicks "Confirm Order"
3. Calls `confirmOrder(id, token)`
4. On success: show green success message, clear the input
5. On error: show red error message

### No table needed
This page has no table, no list, no delete. Just a single-action form.
