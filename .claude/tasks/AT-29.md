# AT-29 — Locale-aware currency/number formatting

## Goal
Render prices and numbers using the active locale + existing currency setting via
the shared `Intl` helpers, replacing manual formatting.

## Requirements
- Use `formatCurrency(amount, currencyCode, locale)` / `formatNumber` from `@acme/shared`.
- Wire the active `locale` (from `useI18n`) + currency code into price display:
  `apps/web/src/hooks/use-pricing-config.ts` and cart/checkout summaries
  (`components/cart/*`, `components/checkout/checkout-cart-summary.tsx`).
- Dates shown to users → `Intl.DateTimeFormat(locale)`.

## Done when
- [ ] Prices show locale-correct separators/currency for en/fr/ar
- [ ] No manual `.toFixed`-style currency concatenation remains in scoped files
- [ ] `pnpm lint` passes
