# AT-25 — Web I18nProvider + language switcher + App wiring

## Goal
Runtime i18n for the web store UI: fetch server translations, resolve/persist the
active locale, expose `t`/`dir`, and add a navbar language switcher.

## Requirements
- `apps/web/src/contexts/i18n-context.tsx` — model on `theme-context.tsx`:
  - On mount call `getTranslationSetting()`; merge server bundle over `enBaseline`.
  - Resolve locale: `localStorage['ayan.locale']` → `navigator.language` prefix →
    server `defaultLocale` → `'en'` (`isLocale` guard from `@acme/shared`).
  - Expose `{ locale, setLocale, t, dir, availableLocales, isLoading }`.
  - `setLocale`: persist to localStorage; set `document.documentElement.lang` + `dir`.
  - Fallback to `enBaseline` on fetch failure (mirror `applyDefaultTheme`).
  - Export `useI18n()`.
- `apps/web/src/App.tsx` — wrap tree in `<I18nProvider>` (inside `ThemeProvider`,
  outside `CartProvider`).
- `apps/web/src/components/language-switcher.tsx` — dropdown over `availableLocales`
  (native names), calls `setLocale`. Add to `navbar.tsx` next to `CartButton`.

## Key files to read
- `apps/web/src/contexts/theme-context.tsx`, `apps/web/src/App.tsx`,
  `apps/web/src/components/navbar.tsx`
